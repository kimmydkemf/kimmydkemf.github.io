# 재설계 2차: 마크다운처럼 보이지 않도록 시각 요소를 더한다

날짜: 2026-10-01

## 배경

재설계 1차를 본 사용자가 "구성은 좋아졌지만 디자인이 너무 없고 마크다운으로 정리한 파일 같다", "모바일에서 프로젝트를 펼치면 글자와 영상 레이아웃이 깨진다"고 했다. 소속도 AX본부 인프라부로 바뀌었다.

## 결정

1. 프로젝트마다 제목 첫 글자 아이콘을 둔다. 색은 slug 로 정해지는 6종 중 하나라 같은 프로젝트는 항상 같은 색이다 (Python/JS 같은 계산, parity 테스트).
2. 카드 왼쪽에 상태 색 띠(진행 중 초록, 일시 중단 황색, 완료 회청), 그룹 제목 앞에 상태 점, 섹션 제목 앞에 강조색 막대를 둔다.
3. 표지에 격자 배경과 상단 강조 띠, 사실 요약 카드에 연도별 시작 프로젝트 수 막대를 넣는다. 이 막대는 실제 데이터에서 나오는 이 사이트만의 시각 요소다.
4. 펼친 내용은 바탕색을 한 단계 달리하고 소제목을 강조색으로 둔다. 모바일에서는 한 열로 고정하고 섹션 사이에 점선을 둔다. 영상은 한 열, 16:9 비율 고정(`aspect-ratio`), iframe `min-width: 100%` 로 iOS 폭 문제를 막는다.
5. 본문의 `overflow-wrap: anywhere` 를 `break-word` 로 바꿔 한국어 단어가 중간에서 끊기지 않게 한다.
6. 소속 표기는 "한국부동산원 AX본부 인프라부".

## 영향

- 데스크톱 페이지 3408 → 3166px. 모바일 가로 넘침 없음, 콘솔 오류 없음.
- 사용자의 실제 휴대폰에서 영상 레이아웃이 어떻게 깨졌는지는 재현하지 못했다 (헤드리스에서는 유튜브 임베드가 빈 상자로 뜬다). iOS 에서 흔한 iframe 폭 문제와 세로 쌓임을 대비해 고쳤다.

## 되돌릴 조건

- 고유 색 아이콘이 산만하다고 느끼면 `.mark` 를 단색으로 바꾼다 (렌더러 변경 없음).
