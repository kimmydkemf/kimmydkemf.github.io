# 기록 현황 카드와 상단 바를 모바일 기준으로 다시 짠다

날짜: 2026-10-02

## 배경

사용자가 모바일에서 테마 버튼이 잘리고, "한눈에" 라벨이 어색하며, 마지막 동기화 날짜 레이아웃이 깨진다고 했다. "웹 프로젝트를 억지로 모바일에 끼워 넣은 느낌"이라는 지적이었다. 재현해 보니 모바일에서 요약 카드를 2열 격자로 바꾸는 CSS 가 연도 막대까지 격자 한 칸에 밀어 넣었고, 날짜 타일은 글꼴이 폴백되면 폭을 넘쳤다. 테마 버튼은 ☀ ☾ 문자가 기기에 따라 이모지로 크게 그려져 잘릴 수 있었다.

## 결정

1. 기록 현황 카드의 마크업을 바꾼다. 연도 막대 → 큰 숫자 4개(`프로젝트 · 진행 중 · 완료 · 과거`) → 한 줄 메타("2017년부터 기록 · 마지막 동기화 2026.10.01"). 긴 모노 문자열을 좁은 타일에 넣지 않는다. 라벨은 "기록 현황".
2. 소속 3줄(현재 · 이전 · 관심)은 데스크톱에서만 보여주고 모바일에서는 숨긴다. 같은 내용이 소개 섹션에 있다.
3. 테마 버튼은 인라인 SVG 해 · 달 아이콘으로 바꾸고 `flex-shrink: 0` 으로 절대 줄어들지 않게 한다. 아이콘 전환은 CSS(테마 토큰과 같은 선택자)로 한다.
4. 모바일 표지는 이름 설명 문단을 숨기고(소개 마지막 문단으로 이동), 버튼은 "프로젝트 보기" 전체 폭 + 두 개 반반, 섹션 여백을 줄인다.
5. 렌더러(Python/JS)가 같은 통계 마크업을 내도록 parity 테스트로 보장한다.

## 영향

- 360px · 390px · 1280px 에서 가로 넘침 없음, 콘솔 오류 없음. 모바일 페이지 높이 4852 → 4522px (390px 기준).
- `#facts` 는 `<dl>` 에서 `<div>` 로 바뀌었다.

## 되돌릴 조건
