# 완료 그룹을 지난 프로젝트로 합친다

날짜: 2026-10-08

## 배경

화면에 "완료 1개"와 "지난 프로젝트 6개"가 따로 있었다. 완료에 있던 Business Calendar Plus 는 상태 값이 없고 마지막 커밋이 2021년이라 자동 분류된 것이었고, 2020년 프로젝트들이 과거인데 2021년 프로젝트가 완료로 따로 서 있어 사용자가 어색하다고 했다. SPEC 의 `completed`(결과물로 의미 있음)와 `archived`(기록 보존) 구분은 화면 그룹으로서는 실질적 차이를 주지 못했다.

## 결정

1. 그룹을 진행 중 · (일시 중단) · 지난 프로젝트로 줄인다. `completed` 와 상태 없음+오래된 커밋은 지난 프로젝트 타임라인에 연도순으로 들어간다.
2. 상태 차이는 카드 배지로 남긴다. 지난 프로젝트 그룹에서는 "과거" 배지만 숨기고(그룹 제목과 중복) 완료 · 미사용 배지는 보여준다.
3. 표지 통계는 프로젝트 · 진행 중(일시 중단 포함) · 지난 프로젝트 3칸으로 줄인다.
4. 필터 버튼은 상태 값 기준이라 그대로 두어 "완료"만 골라볼 수 있다.
5. Featured 는 사용자가 고른 archive 와 life-manager 두 개로 시작한다 (각 레포 portfolio.yml `featured: true`).

## 영향

- 데이터 스키마와 status 값은 바뀌지 않는다. 그룹 배치만 바뀐다.
- Python / JS 렌더러 parity 테스트 대상.

## 되돌릴 조건

- 완료 프로젝트를 따로 강조하고 싶어지면 `GROUPS` 에 `completed` 를 되살리면 된다 (렌더러 두 곳).
