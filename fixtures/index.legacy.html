가계부 자동 등록 (카드/은행 알림 → 텔레그램 봇 또는 MacroDroid POST), 일정 자연어 입력, 월간 요약, 텔레그램 봇 명령어 지원.

주요 기능

  • 2단계 인증 (텔레그램 OTP) — 비밀번호 검증 후 텔레그램 봇으로 6자리 코드 발송, 코드 입력해야만 로그인 완료
  • 자연어 일정 입력 — "내일 오후 2시 팀 회의 #work 긴급" 같은 자유 입력
  • 가계부 — 수입/지출 카테고리 분류, 월간 요약, 일별 그래프
  • 습관 트래커 — 일일 카운트, 캘린더, 완료율 추적
  • 카드/은행 알림 자동 등록 (확인/즉시 모드) — lib/cardParser.js 기반, 가맹점→카테고리 자동 매핑, 5분 중복 방지. 기본 동작은 텔레그램 인라인 버튼으로 등록 여부 확인 후 처리. 대시보드에서 즉시 등록 모드로 전환 가능
